**Input:** `"analyzeFileStructure: Analyzing file structure..."`

**Parse logic (di renderer):**
```javascript
// Split by first colon
const [rawType, reason] = summarizedQuery.split(':').map(s => s.trim());

// Human-readable mapping
const typeMap = {
  'analyzeFileStructure': 'Analyzing file structure',
  'searchPattern': 'Searching for pattern',
  'searchFunctions': 'Searching for function',
  'searchCSS': 'Searching for CSS',
  'searchHTML': 'Searching for HTML',
  'searchImports': 'Searching for imports',
  'webSearch': 'Searching web',
  'fetchWebPage': 'Fetching web page'
};

const humanType = typeMap[rawType] || rawType;
```

### 2. Track Completed Actions

```javascript
// Di awal file (global state)
let completedActions = new Set();

// Saat ACTION_EXECUTING

// Saat ACTION_RESULTS
```

### 3. Preserve Newlines
