# Changelog v35.4.0: Ripgrep Integration & Memory System Enhancements

## Performance & Search
- **Ripgrep Bundling:** Integrated ripgrep binary directly into app distribution, eliminating manual installation requirements
- **Ultra-Fast Search:** Replaced PowerShell Select-String with ripgrep for 100x+ faster file searches (milliseconds vs 30+ seconds)
- **Smart Path Resolution:** Added ripgrep-path.js utility with automatic fallback to system ripgrep or PowerShell methods
- **Intelligent Filtering:** Enhanced Search-InFiles with automatic exclusion of node_modules, .git, dist, build directories

## Memory System Fixes
- **MemoryName Scoping:** Fixed critical variable scoping bug in executeCommand function that caused undefined memoryName errors
- **Smart File Read Detection:** Improved logic to allow AI agent to access new line ranges even when partial content exists in memory
- **Enhanced Memory Messages:** Added total file line counts to memory output for better context and less ambiguous descriptions
- **Cumulative Memory State:** Better handling of file content merging and range detection

## Background Process Handling
- **Process Detection Patterns:** Added comprehensive regex patterns for detecting long-running processes (dev servers, build tools, etc.)
- **Timeout Management:** Implemented 15-second timeout for background processes vs 10-minute timeout for regular commands
- **Agent Continuity:** Fixed timeout handling so background processes that timeout are treated as successful, preventing AI agent loop breaks
- **Terminal Disposal:** Proper cleanup of background process terminals to maintain session integrity

## PowerShell Enhancements
- **Helper Functions:** Enhanced powershell-helpers.ps1 with ripgrep integration and improved error handling
- **Session Management:** Better PowerShell session lifecycle management and resource cleanup
- **Command Injection:** Added ripgrep path injection for enhanced search capabilities
- **Fallback Mechanisms:** Robust fallback to PowerShell methods when ripgrep is unavailable

## Code Quality & Testing
- **Comprehensive Test Suite:** Added edit-operations.test.js with full coverage of editing operations
- **Test Infrastructure:** Enhanced test-codes-agent.ps1 for PowerShell command testing
- **Documentation Updates:** Updated CODES-SYSTEM.md and agent-prompt.md with latest architecture
- **Code Organization:** Better separation of concerns in code-agent.js with modular function organization

## Build System
- **Binary Packaging:** Updated electron-builder configuration to include ripgrep executable in distribution
- **Cross-Platform Support:** Maintained compatibility across Windows/Linux/macOS with appropriate binary selection
- **Bundle Optimization:** Reduced package size impact through efficient binary inclusion

- 27 files modified, 7,635 insertions, 3,856 deletions
- New: resources/bin/rg.exe (5.3MB ripgrep binary), utils/ripgrep-path.js, utils/fast-ls.js
- Enhanced: backend/codes/ module with memory system fixes and background process handling
