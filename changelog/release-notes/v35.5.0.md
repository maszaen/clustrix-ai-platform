# v35.5.0 - Enhanced Command Parsing & AI State Management

## Features
- **Advanced Command Parsing**: Implemented comprehensive command transformation system in `renderer/core/md.js` that converts raw PowerShell commands into user-friendly, informative descriptions
  - Supports 20+ command types including PowerShell helpers, npm, git, file operations, and more
  - Extracts filenames, parameters, and actions for better readability
  - Examples: `Show-FileWithLineNumbers -Path 'file.js' -StartLine 101 -EndLine 141` → "Read file.js, lines 101-141"
- **AI State Management**: Enhanced AI agent workflow with continuation sessions and saved state support
  - Added EXECUTE state for better workflow management
  - Improved memory output with line counts and context preservation
  - State persistence across agent interactions
- **Range Validation Fixes**: Fixed edit operations to handle ranges beyond file length
  - Clamped end ranges for replace/delete operations
  - Improved error handling for AI-generated edit commands

## Changes
- **renderer/core/md.js**: Added `transformCommandText()` function with extensive regex patterns for command parsing
- **backend/codes/code-agent.js**: Enhanced with state management, continuation support, and improved memory formatting
- **backend/codes/codes-prompt.js**: Updated state rules and prompts for better AI workflow
- **backend/codes/edit-operations.js**: Fixed range validation to prevent errors on out-of-bounds operations
- **backend/codes/powershell-helpers.psm1**: Removed redundant PowerShell module file
- **renderer/style.css**: Updated command styling for better UX
- **renderer/renderer.js**: Minor updates for highlighting integration

## Technical Details
- Command parsing supports: Show-FileWithLineNumbers, Search-InFiles, Get-FileContent, Set-FileContent, npm, git, node, python, and generic PowerShell commands
- State management includes: PLANNING, EXECUTING, COMPLETED, ERROR states with persistence
- Range validation now clamps operations to valid file boundaries instead of failing

## Performance
- Improved command readability reduces user confusion and improves workflow efficiency
- State persistence reduces redundant AI processing
- Range clamping prevents unnecessary operation failures

## Breaking Changes
- Removed `backend/codes/powershell-helpers.psm1` - functionality preserved in other modules
