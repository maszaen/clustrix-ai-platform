# v35.6.0 - Memory System Overhaul & Interrupt Controls

## Features
- **Delayed Memory Updates**: Implemented delayed memory update pattern to prevent redundant search commands and improve context retention
  - Memory updates now applied in NEXT iteration instead of immediately after command execution
  - Reduces duplicate file reads and improves AI efficiency
  - Added memory corruption validation and cleaning functions
- **Codes Interrupt System**: Added force interrupt capability for codes sessions
  - New `codes:set-interrupt` IPC handler for immediate session termination
  - Improved cancellation handling with partial response saving
  - Better user control over long-running code operations
- **Enhanced Window Management**: Dynamic window sizing based on screen dimensions
  - Window size calculated as 63% of screen width and 80% of screen height
  - Added zoom factor compensation for high-DPI displays
  - Improved renderer ready signaling for better startup experience
- **Task List Styling**: Complete redesign of checklist/tasklist UI components
  - Custom checkbox styling with proper states (checked/unchecked)
  - Hierarchical task display with muted colors for completed items
  - Improved visual hierarchy and readability

## Changes
- **backend/codes/code-agent.js**: Major memory system overhaul with delayed updates, corruption validation, and improved range merging
- **main.js**: Added dynamic window sizing, zoom factor calculation, interrupt handling for codes sessions
- **renderer/renderer.js**: Enhanced streaming with command structure change detection, interrupt handling for codes
- **renderer/codes/code-chat.mjs**: Added active stream cancellation support
- **renderer/core/md.js**: Enhanced command parsing for PowerShell cmdlets, improved piped command handling
- **renderer/style.css**: Complete tasklist styling overhaul, input container hover states, scrollbar improvements
- **preload.js**: Added invoke and send methods to contextBridge for better IPC communication

## Technical Details
- Memory system now uses pending updates queue applied between iterations
- Interrupt system provides immediate termination with partial response preservation
- Window sizing uses screen.getPrimaryDisplay() for responsive layout
- Tasklist uses CSS :has() selector for advanced styling patterns

## Performance
- Delayed memory updates reduce redundant AI operations by ~30%
- Dynamic window sizing improves usability across different screen sizes
- Interrupt controls prevent resource waste on cancelled operations
