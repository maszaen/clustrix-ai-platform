# Changelog v35.6.1: State Detection & UI Enhancements

## Code Agent Improvements
- **Enhanced State Detection**: Improved AI state parsing with case-insensitive detection and robust validation
  - State names in answer tags now detected regardless of case (e.g., "edit", "EDIT", "Edit")
  - Added validation for state tags to ensure only valid states are accepted
  - Priority system: detected state from answer > valid state tag > null
- **Answer Filtering**: Prevent empty answer chunks containing only state names
  - Filters out meaningless answer content like "EDIT" or "EXECUTE" when AI declares state
  - Cleaner UI experience with reduced noise in responses
- **Git Command Handling**: Added comprehensive git command recognition with detailed descriptions
  - Support for clone, commit, push, pull, branch operations, and more
  - Enhanced command descriptions for better user understanding
- **Dangerous Command Detection**: Expanded security patterns for command blocking
  - Additional dangerous command patterns for better protection

## Claude Agent Integration
- **Confirmation System**: Added high-impact command confirmation for Claude agent
  - Workspace path validation and session management improvements
  - Enhanced system prompt with environment context and task management guidelines
- **Command Execution**: Improved PowerShell command execution with better error handling
  - Session recovery mechanisms for interrupted commands
  - UTF-8 encoding support and workspace validation

## UI/UX Improvements
- **Layout Enhancements**: Increased sidebar width from 260px to 292px for better content visibility
  - Adjusted main window sizing (width: 63%→69%, height: 80%→85%) for optimal screen usage
  - Enhanced command container animations with smooth expand/collapse transitions
- **Command Processing**: Improved command grouping and processing with better visual hierarchy
  - Enhanced markdown parsing with improved command block handling and placeholder processing
  - Better table parsing with handling of extra pipes and malformed structures
- **Keyboard Shortcuts**: Updated from Ctrl+Enter to Alt+Enter for message sending
  - Updated documentation and UI hints accordingly

## Technical Enhancements
- **API Improvements**: Updated confirmation API to support both iteration-based and tool-call-id based confirmations
  - Enhanced IPC communication for better cross-process coordination
- **Performance Optimizations**: Improved AI response parsing efficiency
  - Reduced unnecessary UI updates from filtered answer chunks
  - Added thinking hydration skip for code sessions to prevent UI conflicts
- **Styling Refinements**: Refined border colors and styling consistency across themes
  - Better contrast in dark theme with fine-tuned color values
