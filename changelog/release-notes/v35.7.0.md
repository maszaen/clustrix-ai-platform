# Changelog v35.7.0: Native Multi-Provider Code Agents

## Native Provider Handlers
- **Gemini Native Agent**: Full native Google Gemini API support with function calling
  - Native `contents/parts` structure instead of OpenAI-compatible format
  - Proper `functionCall/functionResponse` handling for tool execution
  - Streaming support with thinking capabilities
  - Stable tool call ID generation for confirmation system reliability
- **OpenAI Native Agent**: Dedicated OpenAI handler with native tool calling
  - Proper `tool_calls` format with function arguments
  - Enhanced streaming with delta content handling
  - Iteration-based stable IDs for confirmation resolution
- **Claude Agent Improvements**: Enhanced confirmation system
  - Stable tool call IDs using `sessionId-iteration-name` format
  - Fixed "Approving..." stuck state on command confirmation

## Shared Prompt System
- **codes-prompt-shared.js**: Centralized system prompt for all providers
  - Single source of truth for agent instructions
  - Consistent behavior across Gemini, OpenAI, and Claude
  - Reduced code duplication (~400 lines consolidated)

## Code Agent Router
- **Provider Detection**: Automatic routing based on model name
  - `gemini-*` → Native Gemini handler
  - `gpt-*`, `o1-*`, `o3-*`, `o4-*` → Native OpenAI handler
  - `claude-*` → Claude handler
  - Others → LangChain fallback
- **Unified Interface**: Single entry point with provider-specific execution

## Edit Operations
- **String-Based Matching**: Improved edit reliability
  - Fuzzy matching for line endings and whitespace differences
  - Better error messages for failed matches
  - Consistent behavior across all agent types

## Documentation
- **edit-operations-guide.md**: Comprehensive guide for edit system
- **demo-edit.js**: Example implementations and test cases
