# Changelog v35.9.0: Portable Mode & Code Agent Improvements

## Portable Mode
- Added portable mode support - run Clustrix from USB/folder without installation
- Created `utils/portable.js` for platform detection and path management
- All data paths (database, config, logs) redirect to `data/` folder next to exe when in portable mode
- Updated electron-builder config with portable target

## Code Agent
- Improved file edit handler with better range handling
- Added context summarization for long conversations
- Enhanced conversation history management with token estimation
- Removed unused files-upload.js and image-handler.js modules

## Database
- Fixed database path resolution for portable vs installed mode
- Improved sync manager path handling
- Better error handling in database initialization

## Architecture
- Centralized data path logic via `getDataPath()` utility
- Updated all backend services to use portable-aware paths:

  - sync-manager.js
  - smart-backup-service.js
  - langchain-service.js
  - local-embedding-engine.js
  - file-summarizer.js
