# Checker Utilities

Directory scanning and analysis tools for the Clustrix AI Platform project.

---

## 📂 `list-directory.js`

A comprehensive directory structure scanner that generates formatted tree views of your project structure with ASCII tree formatting.

### Features

✅ **Two Operating Modes:**
- **MODE_ROOT:** Scan entire project with smart depth policies
- **MODE_DIRECT:** Scan specific directory with full recursion

✅ **Smart Folder Handling:**
- `node_modules/` - Completely skipped
- `.git/`, `.github/`, `.vscode/`, `.claude/`, `out/`, `dist/` - Show folder name only, no contents
- `local_modules/` - Show first level subfolders only
- All other folders - Full recursive scan

✅ **Complete File Listing:**
- All files are printed, not just directories
- Organized with clear visual hierarchy
- Alphabetically sorted for consistency

✅ **ASCII Tree Formatting:**
- Clean tree structure with `├─`, `└─`, and `│` characters
- Professional appearance
- Both console and markdown file output

### Usage

#### MODE_ROOT (Scan entire project)
```bash
node checker/list-directory.js
```

Scans from the current working directory and applies smart depth policies.

**Output:**
- Console display with full tree structure
- File saved: `checker/results/directory-root-<timestamp>.md`

#### MODE_DIRECT (Scan specific directory)
```bash
node checker/list-directory.js <targetDirectory>
```

Scans only the specified directory with full recursion.

**Examples:**
```bash
node checker/list-directory.js backend
node checker/list-directory.js backend/integration
node checker/list-directory.js renderer
node checker/list-directory.js public/images
```

**Output:**
- Console display with tree structure
- File saved: `checker/results/directory-<folderName>-<timestamp>.md`

### File Naming Convention

Generated files follow this pattern:
```
directory-<scanTarget>-<timestamp>.md
```

**Components:**
- `scanTarget`: 
  - `root` for MODE_ROOT
  - Basename of target directory for MODE_DIRECT
- `timestamp`: Epoch milliseconds (Date.now())

**Examples:**
- `directory-root-1761985014829.md`
- `directory-backend-1761985014829.md`
- `directory-integration-1761985014829.md`

### Depth Policies (MODE_ROOT Only)

| Folder Name | Behavior |
|-------------|----------|
| `node_modules` | Skip completely (not printed at all) |
| `.git` | Print folder name only, no contents |
| `.github` | Print folder name only, no contents |
| `.vscode` | Print folder name only, no contents |
| `.claude` | Print folder name only, no contents |
| `out` | Print folder name only, no contents |
| `dist` | Print folder name only, no contents |
| `local_modules` | Print name + direct subfolders only (depth: 1) |
| Other folders | Recursive, full depth (no limit) |

### Error Handling

The script handles errors gracefully:

```bash
# Directory not found
$ node checker/list-directory.js nonexistent
Error: Cannot access "nonexistent": ENOENT: no such file or directory

# Not a directory
$ node checker/list-directory.js package.json
Error: "package.json" is not a directory.
```

No markdown file is created on error; the script exits with code 1.

### Output Location

All generated markdown files are saved to:
```
checker/results/
```

The `results/` directory is automatically created if it doesn't exist.

### Technical Details

- **Runtime:** Node.js (CommonJS)
- **Dependencies:** Only built-in modules (`fs`, `path`)
- **No external packages required**
- **Cross-platform:** Works on Windows, macOS, Linux
