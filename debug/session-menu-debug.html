🔍 Session Menu Debug Injector

📋 Cara Pakai:

  1. Buka aplikasi Clustrix di browser
  2. Tekan F12 untuk buka Developer Tools
  3. Pilih tab "Console"
  4. Copy script dari textarea di bawah
  5. Paste ke console dan tekan Enter
  6. Script akan load dan siap untuk debug

📝 Debug Script (Copy & Paste ke Console)

🎯 Test Cases

Test 1: Hover Button

Hover mouse pada session menu button (3 dots) dan lihat console

Test 2: Open Dropdown

Click button untuk open dropdown, console akan log "OPEN_MENU"

Test 3: Move ke Dropdown (PENTING!)

Dengan dropdown open, move mouse dari button ke dropdown menu items

Lihat console - apa yang terjadi?

  • ✓ Dropdown tetap open? (benar)
  • ✗ Dropdown langsung close? (masalah)

Test 4: Leave Container

Move mouse keluar dari dropdown entirely

Console akan log "LEAVING CONTAINER" dan dropdown harus close

🔧 Console Commands

Setelah script diload, gunakan commands ini di console:

  • showSessionMenuLogs() - Lihat semua logs dalam tabel
  • clearSessionMenuLogs() - Clear semua logs
  • exportSessionMenuLogs() - Export logs as JSON
  • window.debugSessionMenu.eventLog - Lihat raw array

📊 Capture & Share Results

Setelah melakukan test:

  1. Jalankan showSessionMenuLogs() di console
  2. Atau jalankan exportSessionMenuLogs()
  3. Copy hasil logs
  4. Paste ke file atau share ke developer

Screenshot console juga bisa!

🐛 What to Look For

Ketika move mouse dari button ke dropdown, console harus show:

[HH:MM:SS.mmm] MOUSEOUT (on session-menu-container) targetClass: session-menu-btn relatedTargetClass: session-menu-dropdown menuContainerContainsRelated: true → STAYING IN CONTAINER (dropdown tetap terbuka) ✓ action: KEEP_OPEN

Jika bukan itu, ada masalah dan logs akan clear-kan mana!
