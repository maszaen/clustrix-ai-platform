Privacy Policy

Last Updated: October 2025

Pendahuluan

Kami di Clustrix AI Platform ("kami", "tim kami", atau "layanan") berkomitmen untuk melindungi privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, melindungi, dan membagikan informasi Anda ketika Anda menggunakan aplikasi desktop kami.

Aplikasi Clustrix adalah software open-source yang didistribusikan di bawah lisensi MIT. Kami percaya pada transparansi dan kontrol pengguna atas data mereka.

1. Pengumpulan Data

A. Data yang Disimpan Lokal

Sebagian besar data Anda disimpan secara lokal di perangkat Anda dan tidak pernah dikirim ke server kami:

  • Chat History: Riwayat percakapan disimpan di database lokal (SQLite)
  • File Uploads: File yang Anda upload diproses secara lokal
  • Settings & Configuration: Preferensi model, API keys, dan konfigurasi lainnya tersimpan lokal
  • Vector Store: Embeddings untuk memory disimpan lokal tanpa API calls
  • Project Data: Proyek dan session data tersimpan lokal

B. Data yang Dikirim ke Pihak Ketiga (Opsional)

Ketika Anda mengonfigurasi API keys atau mengaktifkan fitur tertentu, data berikut mungkin dikirim ke pihak ketiga:

  • AI Provider APIs: Prompt dan respons dikirim ke OpenRouter, Groq, Gemini, Z AI, atau provider custom yang Anda pilih
  • Web Search APIs: Query pencarian dikirim ke SerpAPI atau Google Custom Search Engine
  • Google OAuth: Jika Anda mengaktifkan cloud sync, email dan token akses Anda digunakan untuk autentikasi
  • Google Drive Sync: Data yang Anda sync disimpan di Google Drive Anda sesuai Terms of Service Google

C. Data yang Tidak Kami Kumpulkan

  • Kami tidak mengumpulkan usage analytics
  • Kami tidak melacak aktivitas pengguna
  • Kami tidak menggunakan tracking cookies
  • Kami tidak mengirim telemetry data ke server kami
  • Kami tidak menjual data pengguna kepada pihak ketiga

2. Penggunaan Data

Data Lokal Digunakan Untuk:

  • Menyimpan dan menampilkan riwayat chat Anda
  • Menemukan informasi dalam file lokal melalui Desktop Search Engine
  • Membuat embeddings untuk memory management
  • Menyimpan konfigurasi model dan preferensi pengguna
  • Memproses file yang Anda upload (secara lokal, tidak di cloud)

Data Pihak Ketiga Digunakan Untuk:

  • AI Completions: Provider AI menggunakan prompt Anda untuk menghasilkan respons
  • Web Search: Search engines menggunakan query Anda untuk mencari informasi
  • Cloud Sync: Google Drive menyimpan data yang Anda sync secara eksplisit

3. Keamanan Data

Keamanan Data Lokal:

  • Database SQLite disimpan di folder user Anda dengan permission lokal
  • API keys disimpan plain text di file config lokal untuk kemudahan debugging (security consideration untuk pengembangan)
  • Tidak ada enkripsi mandatory (Anda bebas menambahkan enkripsi file lokal)
  • Context isolation di Electron mencegah akses arbitrary ke Node.js APIs

Keamanan Data Pihak Ketiga:

  • Komunikasi dengan provider APIs menggunakan HTTPS encryption
  • API keys yang Anda berikan tidak kami simpan atau akses tanpa izin Anda
  • Google OAuth menggunakan standard OAuth 2.0 flow yang aman

Catatan Penting:

Aplikasi ini adalah open-source. Anda dapat membaca seluruh source code untuk memverifikasi praktik keamanan kami. Kami merekomendasikan Anda menjalankan aplikasi ini pada perangkat yang terpercaya dan mempertahankan password yang kuat untuk akun Google Anda.

4. Retensi Data

Data Lokal:

  • Disimpan di perangkat Anda selama aplikasi terinstal
  • Anda dapat menghapus data kapan saja melalui folder userData aplikasi
  • Uninstall aplikasi akan meninggalkan data lokal (manual deletion diperlukan)

Data Cloud:

  • Data yang di-sync ke Google Drive mengikuti retention policy Google Drive
  • Anda dapat menghapus data sync kapan saja melalui cloud folder di Google Drive
  • Logout akan membersihkan session lokal tetapi tidak menghapus data di Google Drive

Data Provider Pihak Ketiga:

  • Provider AI tidak menyimpan chat history secara default (sesuai terms of service mereka)
  • Beberapa provider mungkin log prompts untuk improvement (check TOS mereka)
  • Search engine menyimpan data sesuai kebijakan retention mereka

5. Hak Pengguna

Anda memiliki hak penuh atas data Anda:

  • Access: Anda dapat mengakses semua data lokal melalui folder userData
  • Portability: Semua data disimpan dalam format standar (JSON, SQLite) yang mudah diexport
  • Deletion: Anda dapat menghapus semua data kapan saja
  • Control: Anda memiliki kontrol penuh tentang data apa yang dikirim ke pihak ketiga
  • Transparency: Source code kami open dan dapat diaudit

7. Pembagian Data

Kami tidak membagikan data Anda kepada pihak ketiga, kecuali:

  • Sebagai yang diperlukan oleh hukum: Jika diperlukan oleh otoritas hukum yang sah
  • Dengan penyedia layanan: Untuk fungsi aplikasi (OpenRouter, Groq, Google, dll)
  • Dengan persetujuan eksplisit Anda: Ketika Anda secara aktif menggunakan fitur yang mengirim data (misalnya cloud sync)

8. Cookies & Pelacakan

Aplikasi desktop ini tidak menggunakan cookies atau pelacakan analytics. Kami tidak:

  • Mengirim tracking pixels
  • Menggunakan analytics services seperti Google Analytics
  • Melacak aktivitas pengguna atau penggunaan fitur
  • Membuat profil perilaku pengguna

Website ini (host) mungkin menggunakan analytics minimal untuk keperluan teknis. Anda dapat opt-out dengan menggunakan privacy-focused browser extensions.

9. Privasi Anak-anak

Layanan kami tidak ditujukan untuk anak-anak di bawah 13 tahun. Kami tidak secara sengaja mengumpulkan informasi dari anak-anak. Jika kami mengetahui bahwa kami telah mengumpulkan informasi dari anak di bawah 13 tahun, kami akan mengambil tindakan untuk menghapus informasi tersebut dengan segera.

10. Perubahan Kebijakan Privasi

Kami dapat memperbarui Privacy Policy ini dari waktu ke waktu. Jika ada perubahan material, kami akan:

  • Mempostingnya di GitHub repository kami
  • Memperbarui tanggal "Last Updated" di halaman ini
  • Memberi tahu pengguna melalui release notes aplikasi

Penggunaan Anda yang berkelanjutan terhadap layanan setelah perubahan berarti Anda menerima Privacy Policy yang diperbarui.

11. Informasi Pengembang

Open Source Transparency:

  • Seluruh codebase tersedia di GitHub
  • Lisensi: MIT (free for personal and commercial use)
  • Anda dapat fork, modify, dan deploy versi Anda sendiri

Data Storage Locations:

  • Windows: `C:\Users\[Username]\AppData\Roaming\Clustrix\`
  • macOS: `~/Library/Application Support/Clustrix/`
  • Linux: `~/.config/Clustrix/`

Config Files:

  • `ai-model.conf.json` - Model dan API key configuration
  • `clustrix.db` - SQLite database untuk chat dan data
  • `vector_data.json` - Vector embeddings untuk memory
  • `sync-config.json` - Cloud sync configuration
