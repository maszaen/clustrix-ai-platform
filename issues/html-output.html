## Unordered List (campur-campur)
- Item A (teks biasa)
- Item B dengan *italic* dan `code`
  - Sub B.1 (nested 1)
    - Sub B.1.a (nested 2)
      - Sub B.1.a.i (nested 3)
- Item C dengan paragraf multi:
  
  Ini paragraf kedua di dalam item C. Harus tetap **1 `<li>`**.

  Dan ini paragraf ketiga dalam item C.

- Item D diakhiri dengan code block setelah list (edge-case):

js
// code block langsung setelah list (tanpa <li> baru)
const msg = "Code block setelah list";
console.log(msg);

text 
Teks lanjutan setelah code block di atas. Pastikan parser tidak nempel ke list sebelumnya.

## Ordered List + Nested Numbering

1. Step 1: init
   1.1. Substep 1.1 (format pseudo-numbering di satu paragraf, bukan list sebenarnya)
   1.2. Substep 1.2

   * Campur bullet di bawah ordered:

     * bullet dalam ordered

       1. Nested ordered di dalam bullet
       2. Masih nested ordered
2. Step 2: process

   1. Substep (true nested ordered)
   2. Substep lagi

      * bullet campuran

        * deep bullet
3. Step 3: finalize

Code block setelah **ordered list** (edge-case):

bash
echo "ini code block setelah ordered list"

Lanjut paragraf biasa.
