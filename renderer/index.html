    How to Use Clustrix AI

    Welcome to Clustrix AI!

    Clustrix AI is a powerful, local-first desktop assistant designed for privacy and performance. This guide will help you get the most out of its features.

    Core Concept: Bring Your Own Key (BYOK)

    Clustrix AI operates on a Bring Your Own Key (BYOK) model. This means you connect your own API keys from various AI service providers. Your data is sent directly from your computer to the service you choose. We do not see, store, or process your conversations.

    • Privacy: Your conversations remain private between you and the AI provider.
    • Flexibility: You can use any model from any supported provider, including open-source models.
    • Cost Control: You only pay for what you use directly to the provider. No subscriptions with us.

    Setting Up Your API Keys

    To start using Clustrix AI, you need to add an API key.

    1. Go to Settings > Model lists.
    2. Select a platform from the dropdown (e.g., OpenRouter, OpenAI, Anthropic).
    3. Enter your API key in the "API Key" field. You can get a key from the provider's website like OpenRouter OpenAI Anthropic (Claude)
    4. Model/provider management: You can also manually add custom providers or models directly from this screen. Simply type a new name in the "Platform" field to create a new provider, then add the Base URL, API Key, and specify the model ID. This is useful for connecting to custom endpoints or models not listed by default.
    5. Click Save settings. The application will validate your key and load the available models.

    Key Features

    • Model Switching: Go to Settings > Switch model to change the AI model for the current session.
    • Web Search: Enable real-time web search by going to Settings > Search API and adding a Google Search API key.
    • File Uploads: Drag and drop files (Docx, XLSX, PDF, etc.) into the chat to have the AI analyze them.
    • Projects: Organize your chats and files into projects for better context management.
    • Cloud Sync (Optional): Log in with GitHub in Settings > Account settings to sync your data across multiple devices. This is fully optional and can be disabled at any time.

    Privacy and Policy

    Our Commitment to Privacy

    Clustrix AI is a fully open-source and free desktop platform developed by a solo developer over the past year. We are committed to transparency and protecting your privacy while improving the platform through anonymous usage data collection.

    Important: To continue improving this free platform, we collect anonymous usage data for development purposes. No personal information, location data, device identifiers, or chat content is collected. Only usage patterns, error logs, and interaction data are gathered to help improve the application.

    What Data We Collect (Anonymous)

    For Platform Development & Improvement:

    • Click Events: Button clicks, feature usage patterns, and UI interactions to improve UX
    • Application Logs: Error logs, performance metrics, and crash reports to identify and fix bugs
    • Feature Usage: Which features are used most, session duration, and workflow patterns
    • Database Statistics: Anonymous database size, query performance to optimize the system

    What We DON'T Collect

    Your Privacy is Our Priority:

    • Location Data: We never track or store your physical location
    • Device Identifiers: No device IDs, fingerprints, or unique hardware markers
    • Personal Information: Zero personal data collection - no names, emails, or contacts
    • Chat Content: Your conversations and messages remain completely private
    • API Keys: We never access or store your authentication credentials
    • File Contents: Your uploaded files and their data are never examined

    Why we need this: As a solo developer with no team for user research, this data helps identify bugs, improve the internal reasoning model, optimize LangChain integration, enhance performance, and understand which features to prioritize. All data is anonymized and used solely for platform development.

    Data Storage (Your Personal Data)

    • Local-First: All your personal data—including chat sessions, API keys, and settings—is stored exclusively on your local machine. We do not have access to this data.
    • Bring Your Own Key (BYOK): We do not provide AI models. You use your own API keys from third-party providers (e.g., OpenAI, OpenRouter). Your prompts and conversations are sent directly from your device to the provider's API.
    • API Keys: Your API keys are stored encrypted on your local device. They are never sent to our servers or included in telemetry data.
    • Chat History: All conversation history remains on your device and is never transmitted to our servers.

    Optional Cloud Sync

    • User-Controlled Sync: We offer an optional cloud sync feature using your own GitHub account. If you choose to log in, we create a private repository in your GitHub account to store your data.
    • Data in Your Control: The synced data remains under your control within your GitHub account. We only facilitate the synchronization process. You can revoke access or delete the repository at any time.
    • Your Data Stays Yours: We do not collect, aggregate, or sell any user data, whether stored locally or synced to your GitHub.

    Third-Party Services

    • AI Providers: When you use an API key (OpenRouter, Groq, Gemini, etc.), you are subject to their privacy policy. We encourage you to review their policies.
    • Search APIs: If you enable web search features, queries are sent to SerpAPI or Google Search API according to their terms.
    • GitHub Sync: If you enable cloud sync, your data is stored in your own private GitHub repository according to GitHub's privacy policy.
    • Clustrix AI is not responsible for the data practices of third-party services.

    Your Rights & Control

    • Opt-Out: You can disable anonymous usage data collection in settings or contact us to opt-out
    • Access & Delete: All personal data is on your device - you can access or delete it anytime
    • Export: Export your data in readable formats (JSON, CSV)
    • Open Source Audit: Review our source code on GitHub to verify data collection practices

    Troubleshooting

    API Key Issues

    • Invalid API Key: If you receive an "Invalid API Key" error, verify that your key is correct by checking the provider's website (e.g., OpenAI, Anthropic). Make sure there are no extra spaces or characters.
    • Key Not Recognized: Some providers require specific formatting or have different key types. If using OpenAI, ensure you're using a "secret key" and not an organization key.
    • Rate Limited: If you're getting rate limit errors, check your API usage on the provider's dashboard. You may have exceeded your quota or rate limits.
    • Cannot Save Settings: Restart Clustrix AI and try again. If the problem persists, check that your application data directory has write permissions.

    Chat and Connection Issues

    • No Response from AI: Ensure your internet connection is active. Check that your API key is valid and has remaining credits. Try switching to a different model or provider.
    • Connection Timeout: If the AI takes too long to respond, it may be experiencing high load. Try again after a few moments, or switch to a faster model.
    • Incomplete Responses: If responses are cut off or incomplete, try asking the question again or breaking it into smaller parts.
    • Web Search Not Working: Verify that you've added a valid Google Search API key in Settings > Search API. Ensure your search API has quota remaining.

    File Upload Issues

    • File Not Uploading: Check that the file size is reasonable (usually under 50MB). Supported formats include Docx, XLSX, PDF, and text files. Some formats may require conversion.
    • File Upload Fails: Try uploading a smaller file first to test. If it still fails, restart Clustrix AI and try again.
    • File Content Not Recognized: Ensure your file is not corrupted and is in a supported format. Some encrypted or password-protected files cannot be processed.

    Performance Issues

    • App Runs Slowly: Close other memory-intensive applications. Clear your chat history or archive old sessions to free up space.
    • High Memory Usage: Large files or long conversations can use significant memory. Try breaking work into smaller sessions or reducing the number of simultaneous projects.
    • UI Freezes: If the UI becomes unresponsive, wait a few seconds as the app may be processing. If it persists, restart Clustrix AI.

    Sync and Data Issues

    • Cloud Sync Not Working: Ensure you're logged in with GitHub (Settings > Account settings). Check your internet connection and GitHub authentication status.
    • Data Not Syncing: Manual sync can be triggered from Account settings. If auto-sync fails, try clicking "Sync Now" manually.
    • Lost Data: Local backups are created automatically. To restore, you can manually recover from previous backups stored in the application data directory.
    • Conflict Resolution: If sync conflicts occur, Clustrix AI will attempt to merge changes automatically. In case of unresolvable conflicts, the most recent version is kept.

    Tips

    • Power User Mode: Use keyboard shortcuts to navigate between sessions quickly without touching your mouse. Ctrl+N, Ctrl+Tab, and Enter create a seamless workflow.
    • Browser Back/Forward: Use your mouse's back and forward buttons (or trackpad gestures) to navigate through your browsing history within Clustrix AI.
    • Multi-line Messages: In chat, use Shift+Enter to write multi-line messages. The Enter key alone will send your message.
    • Project Sessions: In project sessions, use Ctrl+Enter to send messages, allowing you to write multi-line messages more easily.
    • Quick Focus: Press / (slash) to quickly focus the message input in chat sessions or the search bar in list pages (Chats, Projects, Artifacts). Saves time without reaching for the mouse!
    • Session Navigation: Ctrl+Tab and Ctrl+Shift+Tab only work when you're in a chat session, preventing accidental navigation when browsing lists.
